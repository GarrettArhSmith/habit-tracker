# PRD: Habitly - Minimalist Habit Tracker

## Project Overview

Habitly is a high-performance, minimalist habit tracker designed for daily consistency. It focuses exclusively on visual progress and personal streaks, removing the complexity of traditional productivity tools.

## Core Principles

- **Extreme Minimalism:** No time-of-day grouping or complex categorizations.
- **Visual Feedback:** High-contrast color coding for different habits and a GitHub-style activity heatmap.
- **Ephemeral State:** Habits are checked off daily and reset every midnight.
- **Personal Best:** Focus on individual streaks and personal completion rates rather than social competition.

## Features & Requirements

### 1. Dashboard (Today's Habits)

- **Daily Progress:** A circular indicator showing the percentage of habits completed today.
- **Habit Cards:** Simple list showing habit name, completion toggle, a 30-day mini-streak visualization, and the signature color.
- **Add Habit:** Quick access to create a new routine.

### 2. Habit Insights (Per Habit)

- **Streak Data:** Current and best streaks displayed as clear numerical values.
- **Total Completions:** Lifetime count of habit check-ins.
- **Activity Map:** 12-month contribution-style heatmap.
- **Appearance:** Option to change the "Signature Color" of the habit.

### 3. Statistics (Global View)

- **Daily Velocity:** Completion ratio for the current day.
- **Activity Intensity:** Combined heatmap for all habits over the last 140 days.
- **All-Time Streaks:** Personal ranking of your own habits by longest current streak.
- **Growth Insights:** Text-based milestones (e.g., peak productivity windows).

### 4. Settings & Theme

- **Theme Toggle:** Three-way switch for Light, Dark, and System modes.
- **Notifications:** Simplified toggles for push reminders and weekly digests.

## User Flows

1. **The Morning Check:** User opens Dashboard -> Taps checkbox for a habit -> Circular progress updates.
2. **Analysis:** User taps a habit card -> Views Activity Map -> Adjusts signature color.
3. **Growth Review:** User taps "Stats" -> Reviews "Growth Insights" for performance trends.
4. **Theme Switch:** User goes to "Settings" -> Taps "Dark" -> UI instantly updates.
